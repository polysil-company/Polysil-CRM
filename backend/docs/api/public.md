# API — Public

> Generated by `scripts/generate_api_docs.py`. **Never hand-edit.**
> Base URL: `/api/v1`. Requests need `Authorization: Bearer <access_token>`
> **except** the four endpoints that cannot carry one - `/auth/login`,
> `/auth/otp/verify`, `/auth/refresh` and `/auth/logout` - and anything under
> `/public`.

Conventions for every endpoint in this file:

- Success: `{ "data": ... }`
- Failure: `{ "error": { "code": "...", "message": "..." } }`. Switch on `code`;
  `message` is for a human and may be reworded without notice
- A `422` is schema validation and uses the same envelope, with a `fields`
  map from field path to reason so a form can mark the offending input
- Money is a **decimal string**, never a number: `"1234.56"`
- Timestamps are ISO-8601 UTC; render in IST
- Every POST/PATCH takes `Idempotency-Key`, and replaying returns the first
  response. **The `/auth` mutations are the exception** and take none: login and
  OTP verify are replay-safe through their own ninety-second windows, and refresh
  is rotation, where a repeat is the case the grace window already handles
- Collections accept `page`, `limit`, `sort`, `q` plus the filters listed
- Rows are already scoped by the caller's permissions. An empty list means
  nothing in scope, **not** an error. A `403` means the action is not permitted at all.

## `GET /api/v1/public/lead-form`

**Lead Form**

What the enquiry page needs before the farmer types: the QR code's label and
campaign (show "Enquiry through Shah Irrigation" at the top), the states, the
irrigation systems and the inquiry types. Districts and talukas come from
`GET /public/territories?parent_id=`.

**Parameters**

| Name | In | Type | Required | Notes |
|---|---|---|---|---|
| `qr` | query | string \| null |  | The code from the page URL, if the farmer scanned one. |

**Responses**

| Status | Body | Meaning |
|---|---|---|
| `200` | `Envelope_PublicLeadForm_` | Successful Response |
| `404` | `ErrorResponse` | An unknown or inactive QR code. |
| `422` | `ErrorResponse` | A field, or `invalid_code`. |
| `429` | `ErrorResponse` | Too many codes for this number or address. |

## `POST /api/v1/public/leads`

**Public Lead**

Create the lead once the code matches. Show the farmer the `inquiry_no`
either way; the acknowledgement also goes by WhatsApp, but it can be held back
(one a day per number), so the page is the place they read it. A retry after a
lost response returns the same number. `invalid_code` covers a wrong, expired
or used-up code: offer to send a new one.

## `GET /api/v1/public/q/{token}`

**Public Quotation**

What the farmer's link shows before the PDF: the number, the seller, the
validity, the total, and whether the document is expired or superseded. **No
name, no mobile, no address, no lines.** Show a "View quotation" button that
opens `pdf_url` in a new tab; do not fetch the PDF on page load, because
messengers fetch a link's landing page to draw a preview the moment the
message is sent, and that must not count as a view.

**Parameters**

| Name | In | Type | Required | Notes |
|---|---|---|---|---|
| `token` | path | string | yes |  |

**Responses**

| Status | Body | Meaning |
|---|---|---|
| `200` | `Envelope_PublicQuotation_` | Successful Response |
| `404` | `ErrorResponse` | Unknown link. |
| `422` | `HTTPValidationError` | Validation Error |

## `GET /api/v1/public/q/{token}/pdf`

**Public Quotation Pdf**

Records the view (the first open moves the quotation to `viewed`; later
opens only count), then redirects to the PDF: a URL valid for ten minutes.
Superseded and expired documents still open. `409 pdf_pending` while the
worker has not finished.

**Parameters**

| Name | In | Type | Required | Notes |
|---|---|---|---|---|
| `token` | path | string | yes |  |

**Responses**

| Status | Body | Meaning |
|---|---|---|
| `302` | - | Successful Response |
| `404` | `ErrorResponse` | Unknown link. |
| `409` | `ErrorResponse` | The PDF is not ready yet. |
| `422` | `HTTPValidationError` | Validation Error |
| `429` | `ErrorResponse` | Too many opens. |
