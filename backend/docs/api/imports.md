# API — Imports

> Generated by `scripts/generate_api_docs.py`. **Never hand-edit.**
> Base URL: `/api/v1`. Requests need `Authorization: Bearer <access_token>`
> **except** the four endpoints that cannot carry one - `/auth/login`,
> `/auth/otp/verify`, `/auth/refresh` and `/auth/logout` - and anything under
> `/public`.

Conventions for every endpoint in this file:

- Success: `{ "data": ... }`
- Failure: `{ "error": { "code": "...", "message": "..." } }`. Switch on `code`;
  `message` is for a human and may be reworded without notice
- A `422` is schema validation and uses the same envelope, with a `fields`
  map from field path to reason so a form can mark the offending input
- Money is a **decimal string**, never a number: `"1234.56"`
- Timestamps are ISO-8601 UTC; render in IST
- Every POST/PATCH takes `Idempotency-Key`, and replaying returns the first
  response. **The `/auth` mutations are the exception** and take none: login and
  OTP verify are replay-safe through their own ninety-second windows, and refresh
  is rotation, where a repeat is the case the grace window already handles
- Collections accept `page`, `limit`, `sort`, `q` plus the filters listed
- Rows are already scoped by the caller's permissions. An empty list means
  nothing in scope, **not** an error. A `403` means the action is not permitted at all.

## `POST /api/v1/imports`

**Upload**

Step 1: upload an `.xlsx` or `.csv` (up to 10 MB and 5,000 rows).

The answer has the column headers, five sample rows, this kind's fields and a
suggested match for each. Nothing is saved to partners, prices or documents
until commit. `target_id` is the draft price list, for `price_list_items` only.
Choose `sheet` and `header_row` when the guess is wrong: the first visible sheet
and the first non-empty row are the defaults.

**Parameters**

| Name | In | Type | Required | Notes |
|---|---|---|---|---|
| `idempotency-key` | header | string \| null |  |  |

**Responses**

| Status | Body | Meaning |
|---|---|---|
| `201` | `Envelope_ImportBatch_` | Successful Response |
| `400` | `ErrorResponse` | `idempotency_key_required` on a write. |
| `401` | `ErrorResponse` | Not signed in. |
| `403` | `ErrorResponse` | No permission for this kind of import. Partner and price imports are staff only. |
| `404` | `ErrorResponse` | No such import, one uploaded by someone else, or one purged after seven days. |
| `409` | `ErrorResponse` | `import_wrong_state` (committed, discarded, not checked, or a lines import at commit); `price_list_published`. |
| `413` | `ErrorResponse` | `attachment_too_large`: over 10 MB. |
| `422` | `ErrorResponse` | `import_unreadable`, `import_too_many_rows`, `import_has_errors`, or `validation_error` with `fields.mapping.<key>`. |

## `GET /api/v1/imports/template`

**Download Template**

A blank file to fill for this import, for the "Download template" link on the
upload screen. Sheet 1 has our column names in row 1 and no rows. Sheet 2, "How
to fill", says what goes in each column, with an example. A filled sheet 1
uploads with every column matched by name.

The same permission as upload. Fetch it with the bearer token as a blob, and
save it as `partner-import-template.xlsx`, `price-list-template.xlsx` or
`order-lines-template.xlsx`: `Content-Disposition` is not readable from another
origin.

**Parameters**

| Name | In | Type | Required | Notes |
|---|---|---|---|---|
| `kind` | query | `partners` \| `price_list_items` \| `lines` | yes |  |

**Responses**

| Status | Body | Meaning |
|---|---|---|
| `200` | - | The blank `.xlsx`. |
| `401` | `ErrorResponse` | Not signed in. |
| `403` | `ErrorResponse` | No permission to upload this kind of import. |
| `422` | `ErrorResponse` | `validation_error`: `kind` missing or unknown. |

## `POST /api/v1/imports/{batch_id}/check`

**Check Import**

Step 2: check every row against a mapping (field key to column index).

Returns the counts, every bad row with its reasons (at most 500), the first 20
good rows as they will be saved, and warnings about whole columns. For `lines`,
`lines` holds every good row for the line editor. Run it again with a new
mapping as often as needed. Saves the mapping, so the next upload of this kind
suggests it.

## `POST /api/v1/imports/{batch_id}/commit`

**Commit Import**

Step 3: save a checked partner or price import. Every row is checked again
first, because masters may have changed. All or nothing: with any bad row and
`skip_invalid` false, nothing is saved (`import_has_errors`, the rows in
`fields` as `rows[<sheet row>].<field>`). A partner import never creates a
login. A `lines` import has no commit: the form saves the lines.

**Parameters**

| Name | In | Type | Required | Notes |
|---|---|---|---|---|
| `batch_id` | path | string | yes |  |
| `idempotency-key` | header | string \| null |  |  |

**Request body**

**`ImportCommitRequest`**

| Field | Type | Required | Notes |
|---|---|---|---|
| `skip_invalid` | boolean |  | Save the good rows and skip the bad ones. Without it, any bad row refuses the whole import. Default `False`. |

**Responses**

| Status | Body | Meaning |
|---|---|---|
| `200` | `Envelope_ImportCommitResult_` | Successful Response |
| `400` | `ErrorResponse` | `idempotency_key_required` on a write. |

| `403` | `ErrorResponse` | No permission for this kind of import. Partner and price imports are staff only. |
